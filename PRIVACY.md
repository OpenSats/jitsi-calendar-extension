# Jitsi Meetings (custom server) privacy

The extension stores your selected server URL and previously selected server URLs locally in your Chrome profile. It reads the event location and description in the calendar editor to recognize existing Jitsi rooms. When you add a meeting, it writes the room link into the event. Saving or sharing that event makes the link available through your calendar provider and to the people you invite.

The extension generates room names locally. Opening a room link connects your browser to the Jitsi server in that link. The extension does not send calendar event data to OpenSats or operate an analytics service.

Removing the extension clears its local settings. Links already saved in calendar events can be edited or deleted in your calendar.
